R1 冷门 CLI（antigravity、trae、zcode、qoder、kimi）的可执行名与非交互参数可能与假设不同。缓解：规则表可用配置覆盖，用真机 --help 采集夹具确认，确认前一律 adapter_unverified、不可选。R2 多数 CLI 没有正式用量接口。缓解：读数尽力而为并标 source 与 at，否则用账本或 unknown，risk 绝不来自 assumed。R3 窗口语义不一且彼此叠加。缓解：多池取最小剩余，估算的重置时间标 estimated。R4 真实探测消耗额度并可能触发风控。缓解：只探测白名单，默认手动，带 TTL，消耗入账。R5 Node 20 修复 CVE-2024-27980 后 win32 的 .cmd 不能直接 spawn。缓解：先解析垫片直接用 node 执行，否则走带参数白名单的 cmd.exe，其余报 E_UNSAFE_ARG；AC-027 自建垫片，不依赖 runner 环境。R6 OS 密钥后端缺失。缓解：报 E_SECRET_BACKEND，只允许 env 或 session，不落明文。R7 注册表与金标冻结过早。缓解：新码或改金标只能走蓝图变更，递增 snapshot_version 并更新迁移文档，实现任务的 write_scope 不含 contracts/golden 与注册表。R8 DSH 宿主在反向代理后面时 loopback 判定可能失真。缓解：loopback 同时校验 socket、Host 与 Origin，doctor 检测代理头并告警，文档要求宿主自带鉴权，默认拒绝。R9 租约跨进程的路径不一致、后续调用过期、进程被杀后悬空。缓解：call 带绝对路径并核对配置摘要，按位置递延过期，启动时回收。R10 Windows 并发改名与锁（EPERM、杀毒占用）。缓解：原子写带重试，锁带 pid 与时间戳，并发测试用屏障。R11 CI 的 Windows runner 没有 WSL 发行版。缓解：解析逻辑全平台单测；AC-038 的 baseline 为 real-smoke，只由维护者真机 real 报告计入；没有这台机器时只能通过 release/waivers.json 显式豁免并单列。R12 check-unused 与 check-no-model-table 是词法检查，可能漏报或误报。缓解：范围限定在 lib，配自测夹具，局限写进文档。R13 forecast 字段语义变化误导旧消费者。缓解：新增 basis 字段，注册表标 semantic_change，check-docs 强制迁移文档覆盖。R14 发现过程误执行恶意同名可执行文件。缓解：未识别的不执行；识别的只跑 --version 与 status，带超时、脱敏、拒读清单。R15 用户本机的 local 配置是占位数据，修复后会被拒绝加载。缓解：返回 E_CONFIG_EXAMPLE 并提示 init 或 config migrate。R16 CLIWORKER_TEST_CLOCK_FILE 可能被误用来延长租约。缓解：设置后每个输出带 W_TEST_CLOCK，health 报 test_clock:true，doctor 判 degraded，文档标明仅供测试。R17 伪时钟与真实子进程混用时，定时器顺序难以推理。缓解：进程内一律用伪时钟加屏障，跨进程只共享时钟文件、不共享定时器，AC-028 只轮询进程是否已死，不断言墙钟。R18 管理会话令牌在内存中，进程重启后 UI 需要重新签发。缓解：UI 遇到 E_ADMIN_REQUIRED 时自动重新请求 api/session（仍只对 loopback 签发）。
